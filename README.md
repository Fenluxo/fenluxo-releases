# Fenluxo releases

The installers and the update feed of Fenluxo, software for PVC window and door manufacturers: https://fenluxo.com

- Windows: `Fenluxo_<version>_x64-setup.exe`
- Android: `Fenluxo_<version>_android.apk`
- `latest.json`: what the installed programs read to update themselves

The program works only with a login from a firm that uses it. There is no code here.
